# Actividad 1 — Programación Mobile

Proyecto demostrativo Android en Kotlin, Jetpack Compose y Material 3. Modela recordatorios inmutables, validaciones y estados mediante `sealed class`, usa `List`, `Set` y `Map`, filtra por prioridad/estado y muestra datos simulados.

## Ejecutar
1. Abrir esta carpeta con Android Studio (JDK 17 y Android SDK 35 instalados).
2. Esperar la sincronización de Gradle. Si Android Studio solicita instalar componentes, aceptarlos.
3. Crear un emulador Android desde Device Manager o conectar un dispositivo Android con depuración USB.
4. Seleccionar `app` y pulsar **Run**.
5. Guardar capturas reales de la estructura del proyecto, la pantalla inicial y la aplicación ejecutándose.

**Alcance:** no incluye persistencia, sincronización ni notificaciones reales: corresponden a módulos posteriores.

**Estado de validación:** código preparado para compilar, pero no compilado ni ejecutado en este entorno; confirmar los pasos 2–4 en Android Studio antes de declarar la actividad terminada.
